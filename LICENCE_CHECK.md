# Licence check

One row per dataset, model or third-party file before it is downloaded or placed in the repo (workspace rule 3).
"Training allowed" and "Redistribution allowed" are read from the licence text, not assumed. The "Covers" column
lists the files under `instances/` that the row releases, as glob patterns, and `tests/test_instances.py` checks
that every instance file is covered by a row whose redistribution answer starts with "yes".

Nothing in this repo trains a model on the data itself. The DQN trains on simulated negotiations over look-up
tables, so the training column is recorded for completeness.
